# Link2Video 用户使用说明

## 🎯 重要说明

**Link2Video 是完全独立的可执行程序，您无需安装Python、虚拟环境或任何依赖！**

## 📥 如何获得程序

1. **下载**: 从开发者处获得 `link2video.exe` 文件（或自己本地使用python环境构建）
2. **运行**: 直接双击 `link2video.exe` 即可使用
3. **无需安装**: 程序可以直接运行，无需任何环境配置

## 🚀 快速开始

### 方法一：直接运行（推荐）
1. 双击 `link2video.exe`
2. 按提示输入视频链接
3. 选择下载模式
4. 等待下载完成

### 方法二：命令行使用
1. 打开命令提示符（Win+R，输入cmd）
2. 输入：`link2video.exe "视频链接" -v`
3. 按回车运行

## 📱 支持的平台

- **抖音** (douyin.com)
- **小红书** (xiaohongshu.com)
- **哔哩哔哩** (bilibili.com)
- **YouTube** (youtube.com)
- **其他1000+平台**

## ⚙️ 下载选项

- `-a`: 只下载音频
- `-v`: 只下载视频
- `-av`: 下载音视频
- `-all`: 下载全部内容（视频+音频+封面+信息）

> 并非全部平台支持选项参数

## 💡 使用示例

### 下载抖音视频
```
link2video.exe "https://v.douyin.com/xxxxx/" -v
```

### 下载小红书视频
```
link2video.exe "https://www.xiaohongshu.com/explore/xxxxx" -all
```

### 下载B站视频
```
link2video.exe "https://www.bilibili.com/video/BV1xxx" -av
```

### 下载YouTube视频
```
link2video.exe "https://www.youtube.com/watch?v=xxxxx" -v
```

## 📁 下载位置

视频将下载到以下位置：
- **默认位置**: `D:\Link2Video\downloads\`
- **或当前目录**: 程序所在目录的 `downloads` 文件夹

## ❓ 常见问题

### Q: 提示"不是内部或外部命令"
A: 请确保 `link2video.exe` 文件完整，或重新下载

### Q: 程序无法运行
A: 请检查：
1. 文件是否完整（约50-100MB）
2. 是否有杀毒软件拦截
3. 是否以管理员权限运行

### Q: 下载失败
A: 请检查：
1. 网络连接是否正常
2. 视频链接是否正确
3. 目标平台是否需要登录

### Q: 某些视频无法下载
A: 部分平台需要登录或VIP权限才能下载高质量视频

### Q: 程序运行缓慢
A: 首次运行需要初始化，后续会更快

## 🔧 高级使用

### 安装到系统（可选）
如果您希望在任何地方使用 `link2video` 命令：

1. 运行 `install.bat` 文件
2. 程序将安装到 `D:\Link2Video\`
3. 创建桌面和开始菜单快捷方式
4. 添加到系统PATH环境变量

### 卸载程序
1. 删除文件夹：`D:\Link2Video`
2. 删除桌面快捷方式
3. 从开始菜单删除快捷方式
4. 从系统PATH中移除 `D:\Link2Video`

## 🚨 注意事项

1. **首次运行**: 可能需要较长时间初始化
2. **网络要求**: 需要稳定的网络连接
3. **杀毒软件**: 可能被误报，这是正常现象
4. **权限要求**: 某些操作可能需要管理员权限
5. **文件大小**: 程序文件约50-100MB
